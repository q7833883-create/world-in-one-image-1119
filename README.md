A pure-Python (standard library only) program that draws a newspaper front page summing up the world news of Thursday 19 November 2026: Anthropic's record IPO debut on Nasdaq, Samsung's $37bn US chip build-out, the first Xi-Trump-Putin summit and the World Court's Myanmar ruling, a yeast-protein trial, and Pochettino's arrival at Manchester United. It renders its own bitmap type and writes a deterministic 1024x1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
